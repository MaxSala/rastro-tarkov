**Rastro é um mapa ao vivo da sua raid para o segundo monitor.** Tire uma captura no jogo e sua posição aparece, com o caminho para cada extração. Suas missões, seu esconderijo, os chefes e seu esquadrão, na mesma tela, sem alt-tab.

Nunca mexe no jogo: só lê arquivos que o Tarkov já grava no seu disco. Gratuito, código aberto, feito por jogadores para jogadores.

## É seguro?

- Lê só arquivos que o jogo grava no disco: os **nomes** das suas capturas e, se você ativar, os logs.
- Nunca lê a memória do jogo, não envia teclas e não desenha nada sobre o jogo.
- Só escuta no seu próprio PC (`127.0.0.1`). Sem telemetria, sem conta.
- Código aberto (MIT). Cada versão é compilada pelo GitHub Actions a partir deste código.

A resposta completa, o aviso do Windows SmartScreen e como verificar o arquivo: [Perguntas e segurança](docs/pt-BR/FAQ.md).

## Comece

1. **Baixe** [`Rastro-windows-x64.exe`](https://github.com/MaxSala/rastro-tarkov/releases/latest/download/Rastro-windows-x64.exe) e abra. Não há nada para instalar.
2. **Siga a configuração rápida.** Ela encontra sua pasta de capturas e baixa os mapas do tarkov.dev.
3. **Tire uma captura no jogo.** Sua seta aparece no mapa.
