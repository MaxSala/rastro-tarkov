**Rastro — живая карта вашего рейда для второго монитора.** Сделайте скриншот в игре, и появится ваша позиция с путём к каждому выходу. Задания, убежище, боссы и ваш отряд на одном экране, без Alt+Tab.

Он никогда не трогает игру: только читает файлы, которые Tarkov и так пишет на диск. Бесплатно, с открытым кодом, от игроков для игроков.

## Это безопасно?

- Читает только файлы, которые игра пишет на диск: **имена** ваших скриншотов и, если включите, логи.
- Никогда не читает память игры, не нажимает клавиши и не рисует поверх игры.
- Слушает только на вашем ПК (`127.0.0.1`). Без телеметрии и аккаунтов.
- Открытый код (MIT). Каждую версию собирает GitHub Actions из этого кода.

Полный ответ, предупреждение Windows SmartScreen и как проверить файл: [Вопросы и безопасность](docs/ru/FAQ.md).

## Как начать

1. **Скачайте** [`Rastro-windows-x64.exe`](https://github.com/MaxSala/rastro-tarkov/releases/latest/download/Rastro-windows-x64.exe) и запустите. Устанавливать ничего не нужно.
2. **Пройдите короткую настройку.** Она найдёт папку скриншотов и скачает карты с tarkov.dev.
3. **Сделайте скриншот в игре.** Ваша стрелка появится на карте.
